# Deple

A rationality/perspective-taking game: drag each alien onto the planet whose response to the day's scenario it would prefer. Hints and "steelman" explanations are generated by Gemma via the Gemini API.

**Stack:** Next.js frontend · Flask + MongoDB backend

## Run

**Backend** (`Backend/.env`: `MONGO_DB`, `GEMINI_API_KEY`, `FRONT_END`)
```sh
cd Backend
python -m venv venv
venv\Scripts\Activate.ps1
pip install -r requirements.txt
flask run          # or: gunicorn app:app
```

**Frontend** (`frontend/.env.local`: `NEXT_PUBLIC_BACKEND`)
```sh
cd frontend
npm install
npm run dev
```
